欢迎阅读 RL 手册。这是一本强化学习指南，旨在将读者从该领域最基础概念一路引领到现代主题。目标是提供一条关于“RL主要思想”的清晰一致的学习路径，同时将数学、代码示例和直觉理解并排呈现。它面向正在研究该领域的研究者和学生，同时也作为那些已经在从事 RL 工作、想要回顾某个特定主题的人的参考资料。本手册是开源的，并且是一份活的文档：新的章节和更新将随着时间的推移不断添加。我是一名 RL 领域的学生研究者，这个项目源于我当初学习这个领域时就希望能拥有这样一份笔记。

本节"引言"旨在作为一个温和的起点。"什么是强化学习？"一章介绍了智能体-环境循环和该领域的基础词汇，而"方法分类"则给出了本手册其余部分所涵盖的算法族的地图。如果你已经有一些 RL 背景知识，可以跳过这两章，直接进入第 1 章，那里开始技术内容。

每章在标题附近还有两个小控件。`复制 Markdown` 会复制该章的源代码，这样你可以将其粘贴到语言模型中，询问某个推导、代码片段或感觉不清楚的段落。`反馈` 会打开该章的 GitHub issue。欢迎纠正、提问和贡献；它们有助于保持本手册的准确性和实用性。

**关于翻译。** 本手册以英语撰写，英语文本是权威来源。本手册也提供其他语言的版本，目前已有中文版本。翻译是为了方便阅读，可能包含不准确之处或滞后于原文（如有余力可以切换到英文版，或许会更有助于你理解概念）；如果你在翻译中发现任何问题，请告诉我们：我们非常欢迎关于翻译的反馈。

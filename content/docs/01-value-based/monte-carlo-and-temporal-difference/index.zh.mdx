> **摘要.** 动态规划通过遍历已知环境模型来评估策略。蒙特卡洛与时序差分方法去掉了这个假设：智能体从采样经验中估计价值。我们仍停留在故事"评估"的一侧：策略保持固定，同时我们学习它的状态往往会产生什么样的回报。

动态规划是精确且干净的，但它假设能访问 $p(s', r \mid s,a)$。在许多 RL 问题中模型不可用。智能体可以行动、观察 $S_t$、$A_t$、$R_{t+1}$ 和 $S_{t+1}$，但它无法枚举每一个可能的下一状态，也无法对转移分布取平均。

本章提出一个更窄的问题：如果策略 $\pi$ 固定，我们如何从采样的片段或转移中估计它的状态价值函数 $v_\pi(s)$？像 Sarsa 和 Q-learning 这样的控制方法在后面。这里我们只做 **基于模型的预测**（model-free prediction，应为"无模型预测"）。

## 告别动态规划

对于一个固定策略，动态规划使用贝尔曼期望更新：

$$
v_{k+1}(s) = \sum_a \pi(a \mid s) \sum_{s',r} p(s',r \mid s,a) \left[r + \gamma v_k(s')\right]
$$

内层求和 $\sum_{s',r} p(s',r \mid s,a)[r + \gamma v_k(s')]$ 正是动态规划使用其最强假设之处。要计算它，智能体必须知道完整的一步模型：从 $(s,a)$ 能到达哪些下一状态、可能出现哪些奖励、以及每一对 $(s', r)$ 有多大的概率。在真实学习问题中，这些信息通常不可用。智能体无法从外部检视转移分布；它只能与环境交互。

无模型预测保留了贝尔曼思想，但改变了访问期望的方式。它不显式地对所有可能的下一状态和奖励取平均，而是把环境当作采样器。智能体采取一个动作，观察一个奖励和一个下一状态，并用那单次转移作为关于"动态规划本会从模型计算出的期望"的证据。一个样本是有噪声的，但许多样本可以逐渐把价值估计拉向同一个对象：固定策略下的期望回报。

两种基本的无模型预测方法是蒙特卡洛学习和时序差分学习；二者都从经验中估计价值，但它们用经验的不同部分作为学习目标。

## 蒙特卡洛预测

**蒙特卡洛预测**（Monte Carlo prediction）通过对访问 $s$ 之后观测到的回报取平均来估计 $v_\pi(s)$。这里的期望就是价值函数，

$$
v_\pi(s) = \mathbb{E}_\pi[G_t \mid S_t = s],
$$

而样本是在环境中遵循策略 $\pi$ 生成的完整回报。假设一个片段在时刻 $t$ 访问了状态 $s$。那次访问的回报是此后观测到的折扣奖励总和：

$$
G_t = R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \cdots
$$

这个 $G_t$ 是那个随机事件"回报"的一个样本，而该事件的期望定义了 $v_\pi(s)$。一个片段给出一个有噪声的样本；许多片段给出许多这样的样本。蒙特卡洛预测存储每次访问状态后观测到的回报，并用它们的样本均值作为价值估计：

$$
V(s) = \frac{1}{N(s)} \sum_{i=1}^{N(s)} G^{(i)}(s)
$$

要点是这个更新不使用转移概率 $p(s',r \mid s,a)$。它不询问从 $s$ 本可能发生什么。它等到看见访问 $s$ 之后实际发生了什么，然后把那些观测到的结果取平均。在这个意义上 MC 预测是无模型的，但它在单步意义上不是在线的：普通 MC 必须等到片段终止，回报 $G_t$ 才知道。

有两种标准变体：

- **首次访问 MC（first-visit MC）：** 在每个片段中，只从该状态第一次出现时更新它。
- **每次访问 MC（every-visit MC）：** 从该状态在片段中的每次出现都更新。

对于首次访问 MC，每个片段对每个状态最多贡献一个回报样本。如果状态 $s$ 在同一片段中出现多次，只有第一次出现之后的回报被加入 $s$ 的平均值。每次访问 MC 则使用所有出现。二者都基于完整回报；区别仅在于允许哪些访问贡献样本。

一个首次访问蒙特卡洛预测过程如下：

```
输入：待评估的策略 pi
对所有状态 s 任意初始化 V(s)
对所有状态 s 把 Returns(s) 初始化为空列表

永远重复，或重复选定数量的片段：
    生成一个遵循 pi 的片段：
        S_0, A_0, R_1, S_1, A_1, R_2, ..., S_{T-1}, A_{T-1}, R_T

    G <- 0
    对 t = T-1, T-2, ..., 0：
        G <- gamma * G + R_{t+1}
        如果 S_t 未出现在 S_0, S_1, ..., S_{t-1} 中：
            把 G 追加到 Returns(S_t)
            V(S_t) <- average(Returns(S_t))
```

因为 MC 使用实际采样的回报而非对未来学到的估计，首次访问 MC 在通常的片段式设定下给出无偏的基于样本的估计。它的弱点是方差：回报包含了从访问直到终止的每一个随机奖励，因此一个不寻常的片段就可能把估计推得远离其典型值。这种高方差是 MC 不为自举所付出的代价。

## 时序差分预测

**时序差分预测**（Temporal-difference prediction）保留了蒙特卡洛的无模型设定，但改变了更新发生的时机。蒙特卡洛要等到片段结束，因为它需要完整回报 $G_t$。TD(0)，最简单的时序差分方法，在观察到下一个奖励和下一个状态后立即更新。

这之所以可能，是因为 TD(0) 使用一步目标。在转移 $S_t, A_t, R_{t+1}, S_{t+1}$ 之后，它把观测到的奖励加上对下一状态价值的当前估计，当作 $V(S_t)$ 的一个新估计：

$$
\text{TD target} = R_{t+1} + \gamma V(S_{t+1})
$$

然后它让旧的估计朝该目标移动一小步：

$$
V(S_t) \leftarrow V(S_t) + \alpha \left[R_{t+1} + \gamma V(S_{t+1}) - V(S_t)\right]
$$

方括号内的量是 **TD 误差**（TD error）：

$$
\delta_t = R_{t+1} + \gamma V(S_{t+1}) - V(S_t)
$$

它衡量两个预测之间的差异。在看到转移之前，智能体对状态 $S_t$ 的预测是 $V(S_t)$。在看到一个奖励并落到 $S_{t+1}$ 之后，它有了一个修订的一步预测：取已经观测到的奖励，再加上当前赋给下一状态的折扣价值。如果这个修订后的预测更大，$V(S_t)$ 就向上移动；如果更小，就向下移动。

这正是 TD 把我们已见过的两个思想结合起来的意义。像蒙特卡洛一样，它从采样经验中学习，且不需要动态 $p(s', r \mid s,a)$。像动态规划一样，它 **自举**（bootstraps）：目标包含 $V(S_{t+1})$，另一个学到的估计，而不是一直等到实际的未来回报直到终止。它可以被描述为从一个猜测学习另一个猜测，但在它们之间插入了一个真实的奖励。

对于策略评估，表格 TD(0) 过程是：

```
输入：待评估的策略 pi
参数：步长 alpha，取值 (0, 1]
对所有非终止状态 s 任意初始化 V(s)
令 V(终止态) = 0

永远重复，或重复选定数量的片段：
    初始化 S

    重复直到 S 为终止态：
        根据 pi(. | S) 选择 A
        采取动作 A，观察 R 和 S'
        V(S) <- V(S) + alpha [R + gamma V(S') - V(S)]
        S <- S'
```

与蒙特卡洛伪代码的重要区别在于更新的位置。TD(0) 不等待片段完成再沿已完成轨迹反向扫描。它在片段内部、每次转移之后立即更新。这使得 TD 自然地适用于长片段和持续任务，其中最终回报可能延迟很久，或者根本不存在。

学习率 $\alpha$ 控制单次转移改变估计的强度。小的 $\alpha$ 缓慢而稳定地平均信息；大的 $\alpha$ 让价值函数对新经验反应迅速，代价是来自单个转移的更多噪声。

## 偏差与方差

蒙特卡洛和 TD 通过偏差与方差的区别最为明显。

蒙特卡洛使用完整回报 $G_t$。如果片段是在策略 $\pi$ 下采样的，那么回报就是 $v_\pi(s)$ 含义的直接样本。这给了 MC 低偏差，但高方差：长片段累积许多随机事件，而它们全部影响更新。

TD(0) 使用一步目标 $R_{t+1} + \gamma V(S_{t+1})$。这通常有更低的方差，因为自举之前它只包含一个采样的奖励。但只要 $V(S_{t+1})$ 是错的，目标就有偏差。在学习早期，它常常就是错的。

蒙特卡洛等待更久，使用一个更干净的目标。TD 更早更新，使用对未来更噪声的估计。正确的选择取决于片段长度、奖励噪声，以及当前价值函数有多不准确。

TD 能在线更新的能力是一个重要的实际优势。它可以在片段进行中学习，并且可以自然地应用于那些无法等待终止的持续任务。

## $n$ 步桥梁

蒙特卡洛和 TD(0) 是一个更大族的两个端点。一个 **$n$ 步回报**（n-step return）等待 $n$ 个采样的奖励，然后自举：

$$
G_t^{(n)} = R_{t+1} + \gamma R_{t+2} + \cdots + \gamma^{n-1}R_{t+n} + \gamma^n V(S_{t+n})
$$

当 $n=1$ 时，这就是 TD(0) 目标。当 $n$ 到达片段末尾时，它变成蒙特卡洛回报。更大的 $n$ 通常意味着更小的自举偏差和更大的采样回报方差。TD($\lambda$) 和资格迹（eligibility traces，我们在此只预览），用指数衰减的权重组合许多 $n$ 步目标。

## 实验：二十一点

可运行示例使用 **二十一点**（Blackjack），即用于引入蒙特卡洛方法的纸牌游戏环境。玩家的目标是用手牌点数比庄家更接近 21 且不爆掉。人头牌算作 10。如果一张 A 可以算作 11 而不爆掉，则它是 **可用的**（usable）。

这是一个很好的无模型预测示例，因为智能体不接收转移表。它只得到片段：一局游戏中可见状态、动作和奖励的序列。脚本中使用的状态是标准的表格二十一点观测：

$$
S_t = (\text{玩家点数}, \text{庄家明牌}, \text{可用 A 标志})
$$

动作集合很小：`0` 表示 **停牌**（stick），`1` 表示 **要牌**（hit）。为了让本章聚焦预测，策略是固定的而非被改进：玩家在点数为 20 或 21 时停牌，否则要牌。任务是估计该策略的价值函数，

$$
v_\pi(s) = \mathbb{E}_\pi[G_t \mid S_t = s],
$$

从许多采样的对局中。赢给出奖励 $+1$，输给出 $-1$，平局给出 $0$。因为奖励只在一局结束时到达，二十一点让蒙特卡洛思想变得具体：一个状态被访问后，回报就是游戏的最终结果。

完整脚本直接实现二十一点动态，而非依赖某个库环境。这让任务可见：发牌、检查可用 A、应用固定策略、产生一个片段，都是普通的 Python 函数。

```python
def fixed_policy(state: State, stick_threshold: int = 20) -> int:
    """高点数时停牌，否则要牌。0 = 停牌，1 = 要牌。"""
    player_sum, _, _ = state
    return 0 if player_sum >= stick_threshold else 1
```

片段生成器返回形如 `(state, action, reward, next_state)` 的转移。大多数要牌转移的奖励是 `0.0`，因为游戏还没结束。如果玩家爆掉，该转移收到奖励 `-1.0`，且下一状态是终止态。如果玩家停牌，庄家打完整局游戏，最后的转移收到 `-1.0`、`0.0` 或 `1.0`。

```python
if action == 1:
    player.append(draw_card(rng))
    if is_bust(player):
        episode.append((state, action, -1.0, None))
        return episode
    next_state = observation(player, dealer)
    episode.append((state, action, 0.0, next_state))
    continue
```

首次访问蒙特卡洛预测等待片段结束，然后沿已完成的游戏反向遍历。对每个状态，它只使用该片段的一个回报样本。下面的价值更新是增量式样本均值：它不把每个回报存进列表，而是直接更新运行均值。

```python
for state, _, reward, _ in reversed(episode):
    returns = reward + gamma * returns
    if state in values and state not in visited:
        counts[state] += 1
        values[state] += (returns - values[state]) / counts[state]
        visited.add(state)
```

TD(0) 使用相同的采样片段，但在每次转移后更新。当 `next_state` 是终止态时，下一价值定义为零。否则，目标从当前对下一二十一点状态的估计自举。

```python
for state, _, reward, next_state in episode:
    next_value = 0.0 if next_state is None else values.get(next_state, 0.0)
    target = reward + gamma * next_value
    values[state] += alpha * (target - values[state])
```

运行脚本 `200_000` 个片段，会打印一些示例价值，并打开一个四面板的价值曲面图：蒙特卡洛和 TD(0)，各自按有/无可用 A 的状态分开。确切数字随随机种子变化，但符号是可解释的。像 `(20, 10, False)` 这样的状态在"20 点停牌"策略下往往不错：玩家已经有一手强牌，即使庄家明牌是 10。像 `(13, 2, False)` 这样的状态通常很差：玩家在固定策略下必须要牌，而很多补牌仍可能导致弱牌或爆掉。

这个示例的重点不是这个策略最优。它没有做控制，也不会根据学到的价值改变自己的行为。重点是展示在一个真实片段式任务上的预测机制：蒙特卡洛等待一局游戏的最终结果并平均完整回报，而 TD(0) 一旦有一个奖励和一个下一状态可用就开始推动价值。

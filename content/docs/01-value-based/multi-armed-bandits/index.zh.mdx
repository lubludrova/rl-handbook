> **摘要.** 多臂赌博机去掉了几乎所有让强化学习变得复杂的东西：没有状态、没有转移、也没有延迟的后果。剩下的只有核心的探索问题。智能体必须决定是去利用当前看起来最好的那个臂，还是去探索那些奖励尚不确定的臂。

引言把强化学习描述为序列决策：智能体观察一个状态、采取一个动作、获得奖励，并转移到新状态。在我们于下一章（马尔可夫决策过程）加入状态和转移之前，先隔离出这个最小版本的问题是有益的——在这里，从奖励中学习已经不再平凡。

这个问题就是 **$k$ 臂赌博机**。$k$ 臂这个名字来自老虎机：每个臂都有一个未知的奖金分布，每拉一次给出一个奖励。智能体希望随着时间获得尽可能多的奖励。这里没有状态需要解读，没有转移模型需要学习，也没有需要估值其价值的未来状态。每一步仅仅是：选择一个臂、观察一个奖励、更新我们对该臂的认识。

这使得赌博机成为 **探索–利用权衡** 最干净的设定。利用（exploitation）指拉动当前估计奖励最高的那个臂。探索（exploration）指拉动另一个臂，因为它可能比估计值更好。在完整的 RL 中，这一权衡与时序信用分配以及状态访问纠缠在一起。而在赌博机中，它以最纯粹的形式出现。

## $k$ 臂赌博机设定

共有 $k$ 个动作，我们称之为臂。在每个时间步 $t$，智能体选择一个动作 $A_t \in \{1, \ldots, k\}$，并收到一个从该臂的奖励分布中采样得到的标量奖励 $R_t$。

在 **平稳**（stationary）赌博机设定下，每个臂的奖励分布在时间上固定不变。今天拉臂 $a$ 和明天拉同一个臂，都是从同一分布中采样。因此每个臂只有一个固定的期望奖励，即它的长期平均支付。我们称这个数为臂 $a$ 的 **动作价值**（action-value），记作

$$
q_*(a) = \mathbb{E}[R \mid A = a].
$$

有两点要注意。第一，$q_*(a)$ 是环境的性质，而非智能体的性质，它仅由奖励分布决定，与智能体做过什么无关。第二，智能体永远无法直接观察到 $q_*(a)$；每次拉动只揭示从该分布中抽出的一个带噪声的样本。整个学习问题就存在于这个鸿沟之中。智能体将从样本中构建一个不断更新的估计 $Q_t(a)$，并试图让它逼近 $q_*(a)$。为了把两者清晰区分，我们把 $q_*(a)$ 称为 **真实动作价值**（臂 $a$ 奖励分布的实际均值），而把 $Q_t(a)$ 简单地称为时刻 $t$ 的 **估计**。符号 $q_*$ 中的星号（asterisk）是 RL 记法中标记"真实/最优版本"的标准方式，你会在后续章节中再次看到。

下一章会推广这个设定：有了状态和转移之后，一个动作的价值不仅取决于它的即时奖励，还取决于它导致的状态。赌博机是只有一个状态、且过去不约束未来的特例。

## 性能度量：累积后悔值

平均奖励很直观，但赌博机算法通常通过 **后悔值**（regret）来比较。后悔值问的是：智能体因为没有始终拉动最好的臂而少收集了多少奖励？

令 $a^* = \arg\max_a q_*(a)$ 为一个最优臂，即真实动作价值最高的那个。如果智能体在时刻 $t$ 拉动动作 $A_t$，那么期望的单步后悔值就是该最优值与所选臂实际价值之间的差距：

$$
q_*(a^*) - q_*(A_t)
$$

在 $T$ 步上的 **累积后悔值**（cumulative regret）就是这些差距之和：

$$
\text{Regret}(T) = \sum_{t=1}^{T} \left(q_*(a^*) - q_*(A_t)\right)
$$

低后悔值意味着智能体很快识别出好的臂，并在差的臂上浪费更少的拉动次数。线性后悔值意味着智能体以大致恒定的速率持续犯着本可避免的错误。次线性后悔值意味着错误的累积速度慢于时间；平均到每步，后悔值会下降。

这种区分很重要，因为一条探索规则不应永远以同样的强度探索。早期的不确定性证明尝试多个臂是合理的。而之后，一旦证据充分，智能体应把大部分拉动用于利用。

## 从样本中估计动作价值

后悔值告诉我们一个算法应当达到什么，却没有告诉我们如何做到。为了能行动，智能体需要每个臂价值的估计，而最简单的估计就是观测奖励的样本均值。接下来的几节将逐步构建出具体的探索–利用算法 $\epsilon$-贪婪、UCB、汤普森采样，它们利用这个估计来保持较低的后悔值。

一个臂价值的最简单估计是它的样本均值。如果动作 $a$ 在时刻 $t$ 之前已被选择 $N_t(a)$ 次，且这些拉动观测到的奖励为 $R_1, \ldots, R_{N_t(a)}$，那么：

$$
Q_t(a) = \frac{1}{N_t(a)} \sum_{i=1}^{N_t(a)} R_i
$$

这里 $Q_t(a)$ 是智能体对 $q_*(a)$ 的当前估计。在平稳赌博机中，随着 $N_t(a)$ 增大，这个估计会变得更可靠。问题在于这是循环的：要估计好一个臂，智能体必须拉动它；但要知道哪些臂值得拉动，智能体又需要估计。

在代码中，样本均值可以增量更新，无需存储每个奖励：

```python
def update_sample_average(old_value: float, count: int, reward: float) -> float:
    """增量式样本均值更新 Q_n = Q_{n-1} + (R_n - Q_{n-1}) / n。"""
    return old_value + (reward - old_value) / count
```

项 `reward - old_value` 是该臂的预测误差。因子 `1 / count` 使得后面的观测比早期观测对估计的移动更小，当奖励分布平稳时这是合适的。

## $\epsilon$-贪婪：最简单的策略

最直接的探索规则是 **$\epsilon$-贪婪**（$\epsilon$-greedy）。以概率 $1 - \epsilon$ 采取贪婪动作，即选择当前估计 $Q_t(a)$ 最大的臂（利用）。以概率 $\epsilon$ 忽略估计，均匀随机地选一个臂（探索）。

对于有限动作集 $\mathcal{A}$，策略为：

$$
\pi(a) =
\begin{cases}
1 - \epsilon + \epsilon / |\mathcal{A}| & \text{if } a = \arg\max_{a'} Q_t(a') \\
\epsilon / |\mathcal{A}| & \text{otherwise}
\end{cases}
$$

这条规则有用是因为它最简单。它保证每个臂都有非零的被采样机会，同时仍把大部分步数花在当前看起来最好的臂上。

它的弱点同样简单：如果 $\epsilon$ 固定，智能体会永远以相同的速率探索。即使在它已经识别出最好的臂之后，它仍会把 $\epsilon$ 比例的步数花在随机动作上。这就产生了 **线性后悔值**：随机拉动的累积代价随时间成比例增长。

```python
def select_epsilon_greedy(q_values: np.ndarray, epsilon: float, rng: np.random.Generator) -> int:
    """以概率 epsilon 随机选择动作，否则采取贪婪动作。"""
    if rng.random() < epsilon:
        return int(rng.integers(len(q_values)))
    return int(rng.choice(np.flatnonzero(q_values == q_values.max())))
```

## 衰减的 $\epsilon$-贪婪

一个自然的修复是让探索随时间衰减。不使用常数 $\epsilon$，而是使用从高位开始并缩小的调度 $\epsilon_t$：

$$
\epsilon_t \propto \frac{1}{t}
$$

在训练早期，智能体广泛探索。之后，它的行为越来越贪婪。在平稳赌博机中，这通常能在经验上给出次线性（$\log T$ 或 $\sqrt{T}$）的后悔值，因为随机拉动很快变得稀少：它们的数量增长像 $\log T$，慢于 $T$。

```python
def epsilon_schedule(step: int, c: float = 1.0) -> float:
    """衰减的 epsilon 调度：epsilon_t = min(1, c / (t + 1))。"""
    return min(1.0, c / (step + 1))
```

比例常数 $c$ 在实践中很重要。当 $c = 1$ 时，调度衰减得如此之快，以至于智能体常常在探索完其他臂之前就锁定到一个次优臂上。把 $c$ 设置在臂数 $K$ 的量级上，能让 $\epsilon$ 在前 $\sim K$ 步保持足够高，以便系统性地扫过所有臂。

精确的衰减调度很重要。衰减过快的调度可能锁定到一个幸运但次优的臂。衰减过慢的调度则会长时间表现得像固定的 $\epsilon$-贪婪。目前重要的想法是方向：当估计不确定时，探索通常应该强；当证据已经累积时，探索应该更弱。

## UCB：面对不确定性的乐观

$\epsilon$-贪婪是随机探索。它不关心哪个臂不确定。**上置信界**（Upper Confidence Bound, UCB）让探索变得有方向性：选择具有最佳乐观估计的臂。

UCB 的动作规则是：

$$
A_t = \arg\max_a \left[ Q_t(a) + c \sqrt{\frac{\ln t}{N_t(a)}} \right]
$$

第一项 $Q_t(a)$ 奖励那些观测到高均值奖励的臂。第二项是一个探索奖励（bonus）。当一个臂只被拉动少数几次时它很大，而当它被频繁拉动时它很小。

奖励的形状很重要。分母 $N_t(a)$ 意味着对反复采样的臂，不确定性会迅速缩小。分子 $\ln t$ 随时间缓慢增长，因此那些被忽略很久的臂会逐渐重新变得有吸引力。常数 $c$ 控制智能体使用的乐观程度。

这被称为 **面对不确定性的乐观**（optimism in the face of uncertainty）。智能体不是偶尔采取随机动作，而是相对一个"上界可信值"贪婪行动。如果一个不确定的臂可能很好，UCB 就会拉动它。如果该臂令人失望，它的样本计数增加，置信奖励缩小，使得下次犯同样错误的可能性降低。

在典型的 UCB1 形式中，对于奖励限定在 $[0, 1]$ 的情况，奖励为 $\sqrt{2\ln t / N_t(a)}$。我们改用带可调 $c$ 的版本。精确的 $\sqrt{2}$ 来自于一个具体的后悔值上界证明，我们在此不展开，并且实践中 $c$ 本来就被当作要调的超参数。

```python
def select_ucb(q_values: np.ndarray, counts: np.ndarray, step: int, c: float) -> int:
    """平稳赌博机上的上置信界动作选择。"""
    untried_actions = np.flatnonzero(counts == 0)
    if len(untried_actions) > 0:
        return int(untried_actions[0])
    bonus = c * np.sqrt(np.log(step + 1) / counts)
    return int(np.argmax(q_values + bonus))
```

第一个分支确保每个臂至少被尝试一次，这样分母 $N_t(a)$ 永远不会为零。之后，动作通过把置信奖励加到当前样本均值估计上来选择。

## 汤普森采样

UCB 用显式的奖励表示不确定性。**汤普森 采样**（Thompson sampling）走的是贝叶斯路线。它为每个臂的均值奖励维护一个后验分布。每一步：

1. 从每个臂的后验中采样一个可能的均值。
2. 选择采样均值最高的臂。
3. 观测奖励并更新该臂的后验。

对于伯努利赌博机，其中每个奖励为 0 或 1，常见的选择是每个臂使用 Beta 后验。一个被成功拉动多次的臂，其后验集中在高均值附近。一个很少被拉动的臂则具有更宽的后验，因此它有时会采样到一个乐观的值而被探索。

结果是概率匹配（probability matching）：在当前后验下，臂被选中的比例正比于它是最优臂的可能性。与 UCB 类似，汤普森采样在不确定性高时探索更多，并随着证据累积自然地变得更贪婪。

```python
def select_thompson(alpha: np.ndarray, beta: np.ndarray, rng: np.random.Generator) -> int:
    """从 Beta 后验中采样并挑选样本最好的臂。"""
    samples = rng.beta(alpha, beta)
    return int(np.argmax(samples))
```

`alpha` 和 `beta` 是每个臂的 Beta 后验参数（成功次数加一、失败次数加一）；该函数从每个后验中抽一个样本，并返回样本最大的臂。

</Callout>

赌博机让我们在没有状态的情况下获得动作价值。下一章通过马尔可夫决策过程加入状态动态与延迟后果。一旦状态和转移进入画面，一个动作的价值就不再是它即时的奖励分布，还取决于该动作会把我们引向何处。
